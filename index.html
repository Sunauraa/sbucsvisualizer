How it works

Four ways to learn each structure, all on the same page.

  1. 01

    Watch it run

    Every operation animates one step at a time, next to the line of code that's running.

  2. 02

    Read the code

    Switch between Java and pseudocode, pause, and step backwards to see what changed.

  3. 03

    Quiz yourself

    Turn on Quiz me and predict what happens next before the step plays.

  4. 04

    Practice

    Each part links LeetCode problems that use it, and the playground runs your own Java.
