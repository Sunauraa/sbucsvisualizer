How the visualizers work

1 · Give it data

Type your own values, or hit Random. Every module accepts custom input so you can replay an exam question exactly.

2 · Run an operation

The algorithm runs and records every step. Nothing is thrown away, so you can scrub the timeline like a video.

3 · Read the caption

Each frame explains itself in words, and the counters track comparisons, swaps, probes, rotations and heights.
