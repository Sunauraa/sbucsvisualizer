Cheat sheet

AlgorithmTime (worst)Space (worst)Best-case timeStableNotes
BubbleO(n²)O(1)O(n)yesearly exit on sorted input

HeapO(n log n)O(1)O(n log n)noin-place, no worst case blowup
MergeO(n log n)O(n)O(n log n)yesneeds a scratch buffer
QuickO(n²)O(n)O(n log n)noaverage O(n log n) time and O(log n) stack; fastest in practice
Two-thirdO(n2.71)O(log n)O(n2.71)no3T(2n/3)+O(1)
CountingO(n+k)O(n+k)O(n+k)yesinteger keys only; k = max − min

Every bound here uses O and means the worst case, unless the column says otherwise.

Any comparison sort needs roughly n log₂ n comparisons in the worst case. Counting sort escapes that limit for one reason: it never compares two keys.
