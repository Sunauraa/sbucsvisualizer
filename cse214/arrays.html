Arrays & Lists

About this topic

The same abstract list, built two very different ways. An array gives you O(1) random access but pays for insertions by shifting. A linked list splices in O(1) but has to walk to reach anything.

A dynamic array's resize copies all n elements into a new array, which is why its worst-case add is O(n) time and O(n) space even though most adds are O(1). Insert-at-index is O(n) for every structure here: the array pays to shift, the list pays to walk. A linked list only wins when you already hold a reference to the node, or when you work only at the ends.
