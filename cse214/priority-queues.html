Priority Queues

One ADT with three operations (insert, min, removeMin) and four ways to build it. Each implementation moves the work to a different place. Then the same ADT gives you three sorting algorithms for free.

A heap never makes you pay O(n) for anything, which is why it is the default choice. Java's PriorityQueue, C++'s std::priority_queue and Python's heapq are all array-based binary heaps.

Insertion sort's phase 1 is only O(n) when the input is already sorted, because each insert stops after one comparison. Heap sort can also run in place by storing the heap in the first part of the input array. The Sorting module shows that version.
