Graphs

Build a graph by clicking and drag vertices wherever you like, even mid-traversal. The adjacency matrix and adjacency list are the same graph in two representations, and they highlight in step with the search.

Click empty space to add a vertex. Click one vertex, then another, to toggle an edge. Drag any vertex to move it.

Real graphs are sparse — E is closer to V than to V², so adjacency lists win almost always. Load the complete K₆ preset and watch the density hit 100%: that is the only regime where the matrix is competitive.

Vocabulary the visualizer uses

degree
edges touching a vertex (in + out if directed)
path / cycle
walk with no repeated vertex / one that returns to its start
connected
every vertex reachable from every other
component
a maximal connected piece — one DFS tree each
tree edge
the edge that first discovered a vertex
back edge
points to a vertex still on the stack ⇒ a cycle
