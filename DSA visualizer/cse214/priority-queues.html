Study notes

One ADT, three operations (insert, min, removeMin), four ways to build it.

Each implementation moves the work to a different place. And the same ADT hands you three sorting algorithms for free.

A heap never makes you pay O(n) for anything. That's why it's the default choice. Java's PriorityQueue is an array-based binary heap.

Insertion sort's phase 1 drops to O(n) only when the input is already sorted. Each insert then stops after one comparison.

Heap sort can also run in place. It stores the heap in the first part of the input array, using O(1) extra space. The Sorting module shows that version.
