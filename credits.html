DSA Visualizer is free and built on other people's generous work. Thank you to everyone below.

Design

The page layouts are adapted from these free Figma Community files, each licensed under Creative Commons Attribution 4.0 (CC BY 4.0). They were changed to fit this site: one navy accent and the system font throughout, and our own text and pictures. Where a creator isn't named here, the linked page names them.

  • Online Course E-Learning Educational Website UI Template (Light Theme): the home and course pages
  • Documentation Website Template by @Arvind03: the module pages and their sidebar
  • Int UI Kit by JetBrains: the code panel and the playground editor
  • Quizzy – Modern Web UI: the quiz
  • Learning-skills-platform: the progress map
  • 404 UX Template: the “page not found” layout

The sign-in button follows Google's own sign-in branding guidelines. The dogs on the “page not found” page and the pictures on the course cards are drawn for this site.

Code

The code editor in the playground is CodeMirror with the Lezer Java parser, by Marijn Haverbeke and contributors, under the MIT License. The full license texts are in third-party notices.

Practice problems

LeetCode problem titles link to LeetCode, where the problems live. DSA Visualizer is not affiliated with LeetCode.
